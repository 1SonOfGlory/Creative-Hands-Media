# Creative Hands Media website

Static website source for a creative-media business, including responsive layouts and a booking interface. The implementation uses HTML, CSS, and browser JavaScript.

Run `python -m http.server 5500 --bind 127.0.0.1` and open http://127.0.0.1:5500. `vercel.json` contains deployment routing where applicable.

Photographs, videos, customer submissions, and hosting credentials are not included in this source snapshot. Replace media references with authorized assets. Booking and third-party services need their own configuration and verification. This repository documents web implementation; it makes no machine-learning claims.
